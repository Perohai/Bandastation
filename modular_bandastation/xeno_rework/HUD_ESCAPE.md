# HUD сопротивления — версия 3

При проглатывании живой жертвы появляется личная панель внизу по центру экрана.
Оформление вдохновлено шкалами борьбы DBD: тёмная подложка, красные акценты,
контрастная шкала и короткие сообщения о попытках. Материалы DBD не используются.

## Управление и сообщения

- Крупное сообщение в чате сразу сообщает о возможности сопротивляться.
- Панель показывает первую клавишу из текущей привязки действия `resist`.
  В штатных горячих клавишах BandaStation используется B. При переназначении
  отображается новая клавиша; при снятой привязке предлагается нажать на панель.
- Работают обычное действие сопротивления, клавиши движения и клик по панели.
  Клик проходит через штатный `victim.resist()`, сохраняя проверки TG.
- Отображаются процент и зачтённые секунды из требуемого количества.
- Засчитанная попытка коротко подсвечивает панель красным. Перед сбросом
  прогресса панель предупреждает о паузе и меняет цвет на янтарный.
- После слишком долгой паузы шкала обнуляется без ожидания следующего ввода.
  Отдельное сообщение объясняет причину сброса.
- При оглушении или потере сознания сообщается, что сопротивление сейчас
  невозможно. Полоса сама по себе не прибавляет прогресс.

## Механика сохранена

Настройки желудка остаются прежними: 90 секунд зачтённого активного сопротивления,
попытка не чаще раза в 1,5 секунды, сброс после паузы более 3 секунд.
Первое нажатие начинает отсчёт. Каждая следующая принятая попытка добавляет
не более 1,5 секунды. Реальное время выхода может быть больше показанного
требования. Клавиша, движение и клик используют один ограничитель;
чередование способов ввода не даёт ускорения. Быстро нажимать не требуется.

Проверки реакции DBD со случайным сектором и штрафами не добавлены.
Свободный выход по заполнению шкалы освобождает только сопротивлявшуюся жертву.

## Изоляция и жизненный цикл

Весь код остаётся в `modular_bandastation/xeno_rework`:

| Файл | Ответственность |
| --- | --- |
| `code/hud/stomach_escape.dm` | Собственные screen-объекты, чтение привязки, подключение к клиенту, обновление шкалы |
| `code/components/swallowed.dm` | Общий прогресс, сигнал Resist, очистка при выходе и смерти |
| `code/organs.dm` | Заметное сообщение при поглощении |
| `icons/stomach_escape.dmi` | Собственная подложка и пиксель шкалы |

Панель добавляется только в `client.screen` текущей жертвы. Другие игроки её
не получают. Штатные HUD, обработчики клавиш и процедуры мобов TG не меняются.
Используется штатная маршрутизация `Resist` в `container_resist_act` собственного
желудка. После освобождения сопротивление снова обрабатывает текущий контейнер
или обычная цепочка моба. Константа `COMPONENT_BLOCK_RESIST` не требуется.

Панель находится на ABOVE_HUD_PLANE, выше эффекта слепоты. При пересоздании
обычного HUD её screen-объекты не очищаются. При отключении или переходе клиента
на другого моба панель снимается с прежнего клиента; при возвращении восстанавливается.
Обновление запускается только для жертвы с клиентом, с частотой SSfastprocess.
При выходе или смерти обработка останавливается, объекты удаляются вместе с
компонентом. Изменённая привязка читается при обновлении без перезахода.

## Установка

Для установленной версии 2 применить `Resist_HUD_Update.patch` из корня билда:

```sh
git apply --check Resist_HUD_Update.patch
git apply Resist_HUD_Update.patch
```

Либо заменить полную папку модуля из архива. Выбрать один способ.
Остальные diff в архиве предназначены для других баз и описаны в README_RU.md.
После сборки начать новый локальный раунд.

## Проверка

Добавлены две регрессионные проверки: штатное действие Resist и общий лимит
попыток со сбросом простаивающей шкалы; удаление объектов HUD при освобождении.
Клиентский рендер, клики и переподключение требуют ручного игрового запуска.
Фактический результат статического анализа и компиляции приведён в VALIDATION.md.

`preview/Stomach_Escape_HUD.png` в архиве — схема оформления, собранная по
тем же размерам подложки. Шрифты и переносы BYOND могут отличаться; схема
не является скриншотом запущенного сервера.
